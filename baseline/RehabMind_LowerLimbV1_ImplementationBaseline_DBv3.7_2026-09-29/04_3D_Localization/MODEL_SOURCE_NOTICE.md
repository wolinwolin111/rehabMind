# 3D Model Source and License Notice

## Current source
- Model source: BodyParts3D
- Data version embedded in the prototype: BodyParts3D 4.0
- Current project asset: optimized adult male reference anatomy, 2,234 source meshes.
- The project also contains a project-specific skin semantic map (`skin_semantics.bin` + metadata) and project-specific localization mappings.
