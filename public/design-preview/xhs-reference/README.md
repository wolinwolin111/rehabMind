# RehabMind 界面提案

四个可点击的静态样式方案。`index.html` 同屏比较，`a.html` 至 `d.html` 展示同一设计的首页、康复思路、处理参考。

参考：小红书《UI鉴赏｜综合生活服务类》，笔记 ID `69e74596000000001b0022ac`。实际读取笔记正文并查看原图后制作；图片只用于本地设计参考。

| 方案 | 配色 | 结构与重点 |
| --- | --- | --- |
| A 清透薄荷 | 薄荷底 `#e7f1ee`，浅薄荷 `#b8ded3`，柔白 `#ffffff`，深青绿 `#255f55` | 全宽部位卡，柔光与透明边缘；深色悬浮导航 |
| B 云霄蓝 | 云蓝底 `#e8f1f7`，云蓝 `#a4cfde`，白 `#ffffff`，深蓝 `#28576b` | 文字与解剖示意并列；大白卡和蓝色胶囊导航 |
| C 浅色分区 | 柔白底 `#eff4f2`，薄荷 `#d1e9df`，浅蓝 `#dce8f4`，淡珊瑚 `#f3ded0` | 部位入口网格；评估方向以真实模块对应色块 |
| D 雾绿留白 | 雾绿底 `#e9efe6`，浅雾绿 `#d4e2d2`，白 `#ffffff`，深绿 `#254c39` | 大间距与白色表面；低阴影、细边悬浮导航 |

字形：英文品牌使用 Avenir Next / Segoe UI；中文标题与正文使用系统 HarmonyOS Sans SC / PingFang SC / Microsoft YaHei。无在线字体依赖。

共同交互：卡片高度连续展开；患者信息展开；症状标签切换；方向标签切换；可能发现打开独立处理参考面板；底部导航切换页面。遵守减少动态效果设置。正文引用既有 `public/design-preview/preview.js` 的示例内容。其余模块只提供布局示意，不代表数据库接入。

解剖图为本地 SVG 部位示意，视角切换仅用于动效演示。正式产品仍采用原有三维模型。

开发期间先在当前允许写入的工作区生成，随后复制到 RehabMind-v2 的 `public/design-preview/xhs-reference/`。没有覆盖正式产品源码或旧预览。
