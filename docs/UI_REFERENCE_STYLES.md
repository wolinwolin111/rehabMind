# 四套配色与组件参考

入口：`http://localhost:5173/design-preview/reference-styles.html`

参考用户提供的小红书笔记《UI鉴赏｜综合生活服务类》中的第 1、2、3、6 张图，制作的是康复思路打开后的样式参考。此轮仅新增独立预览文件，未改正式界面、人体模型和模型定位后的打开方式。

| 图 | 配色 | 组件特点 |
| --- | --- | --- |
| 1 | 薄荷白、深青绿、少量淡紫 | 半透明白卡片、深青绿区域卡片、轻微光晕、深色圆角导航 |
| 2 | 薄荷绿、奶油黄、淡粉 | 彩色内容分区、黑色选中胶囊、柔和圆角卡片 |
| 3 | 烟雨白、云朵蓝、薄荷青、月苍白 | 云蓝至月苍白渐变部位卡片、薄荷青症状卡片与检查区、月苍白处理参考区，保留小圆角深色浮动导航 |
| 6 | 鼠尾草绿、柔白、深森林绿 | 单色分组卡片、森林绿处理参考区、轮廓圆形组件 |

四套使用同一份本地数据库快照，以配色和组件为比较对象。症状卡片、评估卡片和其他相关项目均支持高度逐渐展开及收起；发现项打开独立底部详情。预览底部导航只演示选中状态，不承载正式模块功能。

## 文件

所有预览文件集中于 `public/design-preview/`：

- `reference-styles.html`：对比页面。
- `reference-styles.css`：四套视觉主题及响应式布局。
- `reference-styles.js`：卡片展开、方向切换、底部详情。
- `reference-sample.json`：由本地 resolver 导出的膝部样例，原文保留。

原帖读取文件与四张原始参考图保存在 `build/authoring/`，没有加入产品页面。

## 第 3 套的截图配色映射

主布局沿用原第 3 套。顶部部位卡片采用云朵蓝向月苍白的柔和渐变，其余卡片保持纯色。按用户要求移除春日粉，症状人物图标改用灰蓝色。底部导航采用 16px 圆角横条，按钮改为 10px 圆角矩形，取消圆形按钮。

| 截图色值 | 用途 |
| --- | --- |
| 烟雨白 `#E3E3E5` | 中性底色、边框及其他相关项目，底色与白色混合以减轻灰感 |
| 云朵蓝 `#AFC9DE` | 部位卡片渐变起点、导航选中项 |
| 蓝色 `#7C9FCD` | 评估方向选中项 |
| 薄荷青 `#D6F0EA` | 症状卡片、检查重点及症状选中项；副标题、展开箭头和选项边框统一薄荷色系 |
| 葱绿 `#5E9C76` | 检查图标和选项选中强调 |
| 月苍白 `#F9F6E5` | 部位卡片渐变终点及处理参考分区，方法清单保持统一浅色 |

## 应用到正式产品

用户选定的第 3 套样式已应用于正式产品：`http://localhost:5173/`。

- `src/styles.css`：部位卡片渐变、评估卡片、薄荷青检查重点、月苍白处理参考、小圆角深色导航。
- `src/expandable.css`：薄荷青症状卡片及选项、组内其他相关项目入口、细线展开箭头。
- `src/App.tsx`：复用现有展开与底部详情交互，补充人物、检查和参考图标。
- `src/motion.css`：沿用现有高度过渡、切换和底部详情动效。

人体模型、定位逻辑、点击模型后打开康复思路的方式及数据库原文保持现有行为。

## 分组与字体调整

- 每组使用独立浅蓝灰容器，标题、数量、白色项目卡片及其他相关项目入口归属同一区块。
- 没有主要项目的组直接显示项目名称，不再只显示“其他相关项目”。有主要项目的组保留折叠入口，其他项目在组内展开。
- 项目名称 17px、分组标题与发现名称 15px、正文 14px、操作文字 13px、辅助标签 12px；同一层级展开前后保持一致。
- 模型首页调整标题、说明、工具栏的字号和间距；人体模型和定位交互未改动。

### 浅薄荷与首页布局

- 症状卡片标题固定使用浅薄荷 `#EEF8F4`；展开的表单区域为纯白，选中项保留浅薄荷反馈。检查重点也使用同一浅色。
- 模型首页标题改为“选择不适部位”，提示为“点击人体模型，查看对应的康复思路”，移除重复的“人体定位”标题。
- 桌面模型区最大宽度 960px，居中排布；标题与提示左右对齐，手机上下排布。工具栏左侧为模型名称，右侧为部位选择与视角切换。
- 模型背景改为淡蓝灰 `#F0F4F8`，工具栏及底栏为白色；模型网格、材质透明度、摄像机和定位算法保持不变。
