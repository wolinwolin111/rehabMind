# 页面配色 · 2026-10-02

用户最终选择图 8 的雾蓝、杏黄、浅青，搭配调浅后的米杏白。对应参考页：`public/design-preview/base-comparison/index.html?palette=3`。

| 用途 | 颜色 |
| --- | --- |
| 顶部、评估卡片标题、如何理解标题 | 雾蓝 `#90AFDE` |
| 患者信息、可能发现、选中导航与操作状态 | 浅青 `#9FD9D9` |
| 问诊、周围组织、处理参考标题 | 杏黄 `#EDC98C` |
| 页面、模型背景、展开内容、底部导航底色 | 米杏白 `#FBF7EF` |
| 正文、次要文字 | `#233E50`、`#526877` |

彩色标题展开后保留原色，正文使用米杏白；浅青选中状态使用深色文字。各评估方向共享雾蓝标题，避免旧版紫色、绿色分区覆盖用户选定方案。风险提示保留独立语义颜色；模型肌肉高亮保持绿色。

`src/theme.css` 维护统一色值，组件通过变量使用。三维画布在初始化时读取模型背景；配色修改后需要刷新才能更新已挂载的画布。术后内容本轮不编辑，仅跟随公共界面配色。

# 2026-10-03 补充

- 首页浅青交互区、肌肉图谱有色区域统一为雾蓝 `#90AFDE`；图谱模型画布和解剖正文使用白色。肌肉选中高亮继续使用绿色。
- 周围组织、问诊、患者与症状信息三张入口使用同级浅色 `#EAF8F8`，避免以不同颜色暗示优先级。处理参考仍使用杏黄。
- 四个主模块共用同一个底部导航类：固定 64px、贴底、相同间距和圆角；雾蓝底、浅蓝选中底、深蓝字。删除首页专用尺寸与颜色分支，避免切换跳变。
