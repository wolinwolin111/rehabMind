# 本地肌肉点选试验

## 使用

模型页右侧“肌肉”入口打开独立侧边弹窗。弹窗按需挂载一个模型，默认肌肉与骨骼显示、皮肤隐藏；图层设置仅作用于本次弹窗，不写入主模型设置。
点可见肌肉后，以绿色（#59BD86）高亮该块肌肉，底部显示名称；切换“调整视角”可旋转和缩放，并保留高亮。
主模型保留“选择部位”与“调整视角”；区域定位和康复思路查询沿用原流程。独立图谱不按肌肉直接查询数据库。
弹窗支持关闭按钮、点击遮罩及Escape收起，原生模态框限制焦点并在关闭后恢复入口焦点。打开时暂停主模型渲染，关闭后释放独立模型资源并恢复主模型渲染。
左右圆圈标识已移除。

## 数据与命中

保留 BodyParts3D 原始部件编号、FMA 编号、名称和合并后连续三角面范围。
BVH 使用 `indirect: true`，命中后的原始 faceIndex 查这份索引，避免合并或加速后错认肌肉。
高亮只绘制选中部件的三角面。被不透明骨骼或皮肤遮住的肌肉不响应点选；透明层仅辅助观察。
命中可见网格不代表能从体表推断深层组织，深层肌肉仍需先调整显示和视角。
