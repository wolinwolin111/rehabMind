# 全身模型肌理与分层调整（2026-10-03）

## 已完成的显示处理

- 所有可点选的常用运动肌肉均应用新的肌理映射。长条肌使用主轴圆周映射，薄片肌使用连续平面映射，腹壁四类肌肉使用左右对称的专用方向。主轴通过网格协方差求取，避免斜向肌肉依赖世界坐标的最长边。
- 肌理使用浅表色差、粗糙度变化和受限法线扰动，并按像素尺寸消隐细条纹。不会产生真实几何沟壑，也不修改肌肉附着点。
- 腹壁局部法线平滑减少源网格的小片状高光；保留肌腹形状和腹直肌腱划。
- 全身减层按解剖分区停止在各区最深可用层，修复最后一步把肩胛下肌、腹横肌等已经最深的组织清空的问题。
- 导入的背阔肌、肩胛提肌、肩胛下肌、多裂肌和腹壁肌与既有模型的实际显示分区合并，不再以文案编写时的“补充”栏目充当独立剥离区域。
- 胸壁显示次序调整为：先去除胸部表层覆盖，保留肋间外肌；再显示肋间内肌；最后保留肋间最内肌等深层结构。

## 腹直肌覆盖的处理

腹直肌处于肌鞘中，腱膜覆盖本身符合解剖。源网格把腹斜肌肌腹和腱膜合在一起，并统一使用肌肉材质，造成“深层肌肉包住腹直肌”的观感。

完整教学显示中，按腹直肌连续投影轮廓打开前鞘窗口，边界三角形切分后重新插值法线，避免删除整面形成锯齿。取消原先的18毫米前鞘间距上限，恢复腹直肌下段连续显示。原始坐标与索引数据保持不变；显示几何额外添加切边顶点。减去覆盖层后，深层组织重新显示。单独显示某块肌肉时使用完整源网格。

这属于教学剖露显示，并非把腹直肌向外移动，也不是对全身网格进行真实组织重建。窗口边缘沿平滑投影曲线切分，近距离仍可能看到源模型本身的边界和褶皱。

## 选中碎边与背部穿插复查

普通肌肉选中时直接给当前显示网格着色，取消完整选中网格重复叠加。腹外斜肌等已隐藏的前鞘不再因高亮重新出现，源网格和高亮也不会在同一表面竞争深度。单独显示保留完整组织；已通过的股直肌和共享远端附着修正仍使用其补充几何。

后方射线检查发现，部分髂肋肌及下后锯肌在模型中穿到了背阔肌外面，局部为数毫米。在覆盖肌仍显示时，沿其后方表面切分这些浅小穿插片段；同样检查竖脊肌与更深的背肌。斜方肌覆盖背阔肌、后锯肌覆盖竖脊肌等正常解剖关系保留。剥离覆盖肌后，内层原始表面恢复。该显示处理限于明确的背肌覆盖关系及15毫米以内的局部交叉，不能解释为全身自动解剖认证。

## 参考与验证范围

腹壁体侧面改用绕身体纵轴的径向射线，检查腹外斜肌覆盖腹内斜肌／腹横肌、腹内斜肌覆盖腹横肌的关系。只在覆盖肌存在且局部穿插小于15毫米时切分显示三角面；切边留0.4毫米余量以避免旋转时共面碎片闪现。原始顶点不移动，减层与单独显示仍取完整源组织。左右侧45–135度、腹部23个高度共874条采样射线，原完整显示发现16处深层片段穿出，修正后的同组采样为0；该结果只代表此采样范围。

- 已打开 [Z-Anatomy 在线模型](https://www.z-anatomy.com/)，查看腹直肌及腹部组织菜单；[3DBody 官网](https://www.3dbody.com/)可打开，但本轮未进入其可旋转模型，不能声称完成该模型的逐块对照。

- 静态检查覆盖所有可点选网格：肌理坐标有限、每块肌肉有分层归属、源坐标不变、剥离可逆、点选身份正确。真实 BVH 射线验证完整显示中的双侧腹直肌及减层后的小腿深层肌肉。

## 实际限制

程序化肌理是外观细化，不是测量得到的逐块肌肉纤维走向，尤其不能完整表达羽状肌和扇形肌的区域变化。全身分层是教学剥离顺序，不是等厚的解剖壳层。本轮没有对全身每一处网格穿插做人工几何重建，也没有进行手机 GPU 性能测试。

## 腰方肌与腰大肌完整性复核

去掉第三组肌肉（含腹横肌）后，双侧腰方肌保留。此前只保留网格仍不足以看到它：腰大肌及胸腰筋膜前层继续遮挡其前方。胸腰筋膜后、中、前层现分别随第 1、2、3 次减层隐藏；单独显示肌肉时也不保留这些遮盖壳层，明确单独选择筋膜时仍可查看完整筋膜。

曾经为增加正面可见面积在腰大肌及节段性深背肌上打开局部窗口，但这会切断腰大肌，用户指出后已完全撤销。当前仅移除相应筋膜，腰方肌、腰大肌保留完整源表面与附着位置；不以某个视角的可见面积百分比作为删掉另一块肌肉的理由。从正面可以点选外侧露出的腰方肌，转至同侧斜前方可见面积增加。

验证逐一比较左右腰方肌及腰大肌的所有源三角形，确保数量与坐标完整保留。射线同时包含可见肌肉、骨骼及连接组织，并与完整源组织的遮挡和身份结果比较。浏览器已实际减去三层，从正面点选“左侧 · 腰方肌”并旋转核对连续腰大肌；两块肌肉可同时显示。界面应用用户确认配色，移除图谱上方两条横栏，仅保留模型右侧的“肌肉＋／肌肉－”按钮。
