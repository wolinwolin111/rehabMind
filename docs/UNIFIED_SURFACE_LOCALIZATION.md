# 统一表面定位实施记录

日期：2026-10-01。以下前半部分记录首次小腿重标，末尾记录用户要求的整条下肢及足部复校。当前运行资源已使用完整复校标注。

## 一套运行机制

点击模型 → 射线命中原皮肤三角面及实际落点 → 读取该落点的表面标注 → 打开既有定位入口 → 数据库提供周围组织及康复思路。

`src/localization.ts`只负责读取标注及通用三角形坐标，不包含膝、小腿、踝或大腿的坐标阈值，也不再包含 `fallbackArea`、`medialPointArea`、旧标签优先返回等分支。左右侧、正中位置、模块及显示名称来自标注记录。

界面不根据观察方向决定区域；前、后、侧面及旋转后的视角使用同一份表面标注。射线仍命中皮肤表面，不因透明皮肤下看到了骨骼就直接认定深层组织。

## 标注来源与范围

| 内容 | 位置 | 用途 |
| --- | --- | --- |
| 当前模型标注配置 | `scripts/surface_regions.json` | 小腿完整截面分区、骨面参照、两端交界及范围选择关联 |
| 标注生成 | `scripts/surface_atlas.py` | 读取原网格及解剖参照，生成表面区域标注；部位专属标注处理仅在生成阶段 |
| 统一资源导出 | `scripts/prepare_3d.py` | 导出原模型及标注，与开发、构建和测试流程相连 |
| 实际运行资源 | `public/3d/skin.json`、`surface_atlas.bin` | 区域入口字典、每个三角面的标注及边界细分 |
| 点击读取 | `src/localization.ts`、`AnatomyStage.tsx` | 解码标注、按实际落点读取入口；不自行生成临床内容 |

现有左右胫骨网格提供各高度的前缘参照，皮肤截面提供实际中心与尺度；骨骼资源ID及位置哈希保存在生成审计中。髌骨、腓骨参照用于校核近端范围。配置中的高度、角度是当前模型的标注参数，不是通用人体或诊断边界。

区域包括胫骨前缘、胫骨内侧、小腿前侧肌腹、外侧、后侧上段、后侧中下段、后内侧及相应交界。原临床区域ID保持不变；胫骨内侧、后内侧和膝后交界沿用既有定位指南。真正前膝、腓骨头及跟腱入口分别保留。

跨界三角面采用四分细化，实际点击点通过三角形内的位置读取对应子区域，避免整个大三角面只返回一个标签。只细分标注，未改变皮肤或骨骼几何。最终跨界叶子面最大边长约2.5毫米，这是标注粒度，不是经临床测量的定位误差。

原 `knee_calf_surface.json`、`lower_leg_medial_surface.json`及历史审计保留作追溯，当前资源生成不再执行这两个局部补丁。网页不再加载旧 `skin_semantics.bin`，当前公开元数据也不再包含旧坐标回退契约。

## 已修正的案例

| 原问题 | 本轮结果 |
| --- | --- |
| 小腿上段前外侧进入髌下/髌腱 | 相同保存落点返回小腿前侧；纯外侧落点返回小腿外侧 |
| 上段纯外侧进入膝后交界 | 膝后交界限制在后方，纯外侧不再归入该入口 |
| 后侧稍偏内进入后内侧 | 后侧中央及后方稍偏内保留后侧；明确后内侧仍能进入后内侧入口 |
| 胫骨前缘进入前侧肌腹 | 对照实际胫骨前缘参照，前缘、旁侧肌腹与内侧分别返回对应入口 |
| 小腿与踝的标注空隙 | 补齐两端交接，斜向射线落入该处能读取有效入口 |

划线、圈选通过同一标注获取覆盖区域。已定义的膝后/小腿上段跨界可以进入既有交界指南；膝部范围圈选也移至数据配置。没有合适交界指南的混合范围仍保留主要覆盖区域，不随意拼接任意组织，也不增加确认步骤。

## 拓展方式

运行格式不绑定下肢，支持新的区域ID、左右/正中位置、单区域及交界入口。自动测试用脊柱、骨盆、上肢及新模块的模拟标注确认读取算法可复用，未接入这些部位的正式内容。

后续拓展需要为新部位制作并审核表面标注、注册定位入口、补临床内容。标注制作须根据新部位解剖调整；不把小腿截面模板直接套到脊柱、骨盆或上肢。运行时仍使用同一套三角面读取算法。

## 整条下肢与足部复校

用户反馈大腿下段后方、外侧进入膝，要求对整条下肢与足部重新校准。静态复查确认旧膝标签在生成时优先于大腿标注；旧标签向上延伸到模型y约0.559，导致此问题。现已取消原语义标签及契约的输入依赖，统一按新标注生成，不保留旧标签抢先返回。

### 范围

- 大腿：实际皮肤截面校准中心、尺度和前后内外侧；覆盖内侧靠中线的表面。非前方的大腿下段不再归膝。真正髌上/股四头肌腱邻近保留一小段前方交界，边界依据当前模型的髌骨与股骨位置制作。
- 膝：按实际髌骨宽度区分中央与内外缘，关节线、腓骨头、后内侧、后外侧及膝后入口分别标注。与大腿、小腿边界连续。
- 小腿：保留已通过回归的胫骨前缘、内侧、肌腹、后内侧和膝后交界标注；不退回旧方案。
- 踝足：以跟骨到跖骨头的实际足轴为参照，结合足部骨骼和表面方向区分踝前内外后、足跟、足底足弓、足背中足、舟骨内侧、第五跖骨基底、跖骨头及第一跖趾关节。舟骨内侧与足背中足已分别抽样修正。
- 足趾：新增 `LOC-TOE-HALLUX`、`LOC-TOE-LESSER`。表面显示拇趾与第2–5足趾，复用既有长屈伸趾肌相关检查、根部跖趾关节活动、力量与控制；趾端不再显示为跖骨头。没有新增趾间关节、趾端局部或甲周问题内容。

指南中 `Auto_Apply_To_Region` 为可选布尔字段，false表示必须按该入口显式查询，空值保留原区域自动关联。足趾引用原跖趾区域作为内容所属模块，不自动替换该区域的指南。既有歧义检测仍有效，不任意挑选重叠默认指南。重建内容脚本包含足趾覆盖文件，避免再生成时丢失。
