# 术后康复专业阅读版

日期：2026-10-02。

## 阅读结构

术式目录 → 治疗路径及保护重点 → 单个阶段 → 目标、评估重点、训练参考、进阶依据 → 限制与异常反应 → 回归活动、参考文献与原文。

主阅读页使用原生 React 内容，随页面滚动，不再把完整旧站塞进固定高度的 iframe。手机端横向选择阶段，桌面端使用左侧阶段索引。字号按标题、模块标题、正文和辅助标签统一。

## 内容来源与编辑范围

- 6 份服务器导入原文保持字节一致，原有解剖图和全文可从参考资料入口打开。
- 从原文提取 29 个术后／断裂阶段、137 个动作参考及各阶段的保护条件、进阶依据、异常反应和原文文献链接。
- 跟腱原文还含跟腱病路径；它不混入本模块的修复／部分断裂阶段，完整内容仍保留在原文。
- 原 HTML 存在不平衡的 div 标签，部分第一阶段动作脱离阶段容器。提取脚本按源文件中阶段边界读取，避免漏掉第一阶段动作。
- 主页面以方法名称呈现训练；展开查看用途与负荷观察。患者动作分解、组数、次数、居家自查不进入主阅读结构。
- 评估重点由对应阶段目标、进阶条件和限制归纳；没有新增统一处方、自动分期、诊断判断或填写结果流程。
- 半月板部分切除与修复使用不同目标／限制覆盖，不共用数字时间窗；根部、复杂修复列为专属方案。
- ACL 与 PCL 非手术路径、翻修、多韧带及跟腱重建增强只展示原文中的适用范围、保护与衔接，不借用重建／急性修复阶段表。
- 髌骨非手术与单纯 MPFL 可参考共同能力方向，去除混合时间窗；截骨、软骨处理与骨性矫形保留独立保护边界。

## 纠正的易误读内容

- 大腿围度不能代替关节积液评估，ACL 早期进阶改为直接描述积液与负重反应。
- ACL 跑步及回归运动不只看周数和双侧对称指数，专业阅读版保留力量、动作质量、绝对能力、心理准备与专项暴露。
- 原文把半月板修复的 6–9 个月与起跑混在一句，专业版不沿用该起跑时间描述。
- 联合术后深屈膝、跳跃和旋转不使用统一四个月解禁条件，按照具体修复路径和手术限制衔接。

编辑时核对了 [Aspetar ACLR 指南](https://www.aspetar.com/en/professionals/aspetar-clinical-guidelines/recommendations-on-rehabilitation-after-aclr)中组织保护、运动训练和进阶标准的框架。其余文献沿用各原文的出处；此次没有重新核验每个动作的全部证据，也没有将整理结果声称为独立临床实践指南。
