# 模型加载优化（更新于 2026-10-04）

## 显示与定位分开

首页使用 `home-muscles.pack` / `home-bones.pack` 精简显示资源，分别保留结构边界，在 3 mm 网格内归并显示顶点；使用已修正的腹壁／背部轮廓与平滑法线，关闭细微程序肌理。原始 `skin.pack` 和 `surface_atlas.bin` 继续负责点选、划线、圈选，定位规则及数据库不变。

图谱使用完整三角拓扑的预处理显示资源，保留肌理和可点击组织 ID。原始肌肉资源、股直肌与肱二头肌等已通过的单独显示修正按首次肌肉选择加载，不阻塞初次打开。显示资源位置压缩误差小于 0.02 mm；源模型及附着修正保持原样。

## 计算提前与缓存

`scripts/authoring/prepare_model_display.mjs` 在 `npm run assets` 中预先计算四次减层的显示结果、穿插修正、法线平滑、肌理坐标与 BVH。BVH 使用间接索引，不改变组织面范围。源资源／分层／处理代码变化时自动重建，否则复用资源；显示清单纳入 Vite 资源版本。

运行时共享解压后的只读资源，去掉隐藏皮肤外观、毛发和首页不使用的连接组织加载。缓存保留两个共享数据池、图谱初始层及一个其他层；每层仅组装当前可见的 GPU 属性，上一层几何及时释放。静止或首页被图谱覆盖时不重复绘制；首页像素比上限 1.35，图谱仍为 1.8。

肌肉完整单独显示模块（含股直肌修正网格）改为首次选择肌肉时加载。生产首屏 JavaScript 压缩传输体积由约 1,067 KB 降为 273 KB；后续模块约 795 KB。

## 本机测量与边界

Node v22.16.0 / Windows，测量不包含网络和 GPU，非手机端完整打开时间：

| 路径 | 时间 |
| --- | ---: |
| 原来的首次显示计算：裁剪、平滑、肌理、BVH | 9,047 ms |
| 新首页肌肉：解压与还原 | 39 ms |
| 新图谱初始层：解压与还原 | 147 ms |
| 新图谱第三次减层：解压与还原 | 26 ms |

首页骨骼与肌肉下载合计由 17,759,065 字节降为 5,493,153 字节（减少约 69%）；显示三角形由 1,240,658 降为 581,951（减少约 53%）。其他必需定位资源仍加载，因此这两个比例仅针对显示模型。

图谱初次显示包约 16.7 MB，完整骨骼约 4.2 MB；包含预计算肌理和 BVH，首次网络传输仍可能等待，手机实际时间取决于带宽及硬件。首次选择肌肉会继续加载约 13.5 MB 原始细节；此前选过则复用。每层首次下载按需进行，界面显示载入状态并阻止连续减层。

## 分层资源共享（2026-10-04）

五份显示包原来重复存储顶点、法线、肌理坐标及三角形。现在由 `atlas-shared-0.pack` 保存初始层公共数据，`atlas-shared-1.pack` 保存深层新增数据；各层只保留组织范围、共享三角形块引用和预计算 BVH。共享顶点的身份包含法线和肌理，裁剪后属性不同的顶点不会误合并。

| 指标 | 原分层包 | 共享分层包 |
| --- | ---: | ---: |
| 全部分层显示资源 | 41,085,823 B | 23,603,321 B |
| 初次显示所需肌肉数据 | 16,688,015 B | 16,690,676 B |
| 首次减一层新增数据 | 12,728,481 B | 4,588,802 B |
| 第二次减层新增数据 | 8,294,615 B | 1,671,648 B |
| 第三次减层新增数据 | 3,374,574 B | 652,118 B |

初次显示不加载深层新增数据；首次减层后该池保存在内存，后续层复用。APK 内包含两份共享池，安装后读取本地资源；上述字节数对应网页首次请求资源量。首页轻量显示资源保持原样。

本机 Node v22.16.0 / Windows 一次基准中，初始层解压与组装 178 ms（优化前基准为 160 ms），后续减层依次 112 / 50 / 19 ms；不包含网络、GPU 和手机实测。共享增加少量组装工作，下载量下降，不能据此宣称所有手机都更快。

对旧显示包逐三角形核对：五个状态面数及组织范围一致，法线和肌理值一致，位置最大差异 0.024 mm（不同量化边界导致，距原始表面误差仍小于 0.02 mm），800 条前后视角射线命中组织一致。页面实际操作验证四次减层至骨架、四次加层恢复、骨骼和腰大肌点选、单独显示；无浏览器错误。176 项自动测试全部通过。

基准命令：`node scripts/authoring/benchmark_model_display.mjs`，报告输出到 `build/authoring/model-performance.json`。资源及定位回归测试见 `tests/prepared-model.test.mjs`。
