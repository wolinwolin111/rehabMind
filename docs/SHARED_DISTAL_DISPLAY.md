# 分头肌肉的远端显示补充

日期：2026-10-03。已进入本地产品的高亮和单独显示；未部署。

## 修改范围

| 所选肌头 | 来源 | 补充原三角面（右／左） | 来源全部三角面（右／左） |
|---|---|---|---|
| 肱二头肌短头 FJ1512 / FJ1512M | 同侧长头 FJ1478 / FJ1478M 的末端片段 | 127 / 122 | 492 / 492 |
| 尺侧腕屈肌尺骨头 FJ1518 / FJ1518M | 同侧肱骨头 FJ1473 / FJ1473M 的末端片段 | 279 / 265 | 680 / 674 |

原全身肌肉包、源身份全部保留。新关系写入skin.json所选肌头的sharedDistal属性，记录候选原三角面。单独显示及高亮时使用派生显示几何；原来源肌头自身的显示不变，不添加对侧或整个来源肌头。

分割平面位于受补充肌头源模型下端稍上方，保留少量重叠以显示连续路径；肱二头肌5 mm、尺侧腕屈肌30 mm为本源模型的显示分割参数，不是通用解剖分区或组织学肌腱边界。左右分别选面并保存来源几何哈希。

接缝修正：只取完全低于平面的面会漏掉连接面，保留整块跨线面又会产生向上岔出的尖角。尺侧腕屈肌沿用平面裁切与渐进收拢，原肌头和补段靠骨端原三角面不变。

肱二头肌：原来两块重叠薄片的接缝改成连续曲面。按真实边界边序提取上下源截面，经32段渐细截面连接；源边缘方向拟合接出切线，并在两处接缝的局部带内圆顺。边界共用顶点，计算连续法线，绿色肌腹到米白肌腱渐变。当前本模型修正带约y=1.1233至1.1723，约49 mm；这只是本模型显示参数。带外原肌头及靠骨端的源三角面位置保留，取消补充恢复源显示；不改源包。这属于教学显示过渡，不是真实腱束重建。预览页提供“连接处放大”并可隐藏骨骼，便于旋转检查接缝。

圆顺之后约束局部过渡截面面积从肌腱向肌腹渐增，消除截面拟合造成的中段凸包与反复收缩；保留两端共享边界和原骨端。测试检查各截面趋势，避免仅凭单一角度判断是否圆顺。

## 解剖说明与限制

- [AAOS肘部肱二头肌资料](https://www.orthoinfo.org/diseases--conditions/biceps-tendon-tear-at-the-elbow/)说明远端肌腱到桡骨的连接；本次补充用于观察该路径，未区分两头的精细腱束。
- [Texas Tech前臂表](https://anatomy.ttuhscep.edu/schemes/forearm_tables.html)说明尺侧腕屈肌到豌豆骨及远端延续的关系。
- 这些片段依旧来源于肌肉整块网格，不冒充原资源中独立存在的具名肌腱，也没有生成新组织或重建骨面足印。
- 肱二头肌派生显示已在局部焊接共享边界；几何连续不代表真实腱束或组织学边界的精度。
- 用户复核大小菱形肌连接点正确：原模型保留，校准试验及错误修模提示已撤下。

## 验证

6项测试验证来源身份、几何哈希、同侧关系、肱二头肌修正带外及靠骨端的源三角面相等、共享边界封闭且绕序相反、颜色渐变、无塌缩三角面、原数据未被修改、原来源肌头不受影响。尺侧腕屈肌保持原有保留范围检查。左右四个补充结果与原肌头有表面接触，远端实际射线可达。TypeScript检查同步通过；在核查页观察接缝。工程验证不等于精细附着认证。

现成工具评估：[three-bvh-csg](https://github.com/gkjohnson/three-bvh-csg)可做网格布尔合并，但要求封闭双流形输入且仍有数值限制；[Manifold](https://github.com/elalish/manifold)提供拓扑布尔工具。这些工具不决定解剖形态。本次采用局部平面裁切与显示过渡，复用已安装的three-mesh-bvh做接触和射线验证，未增加布尔库依赖。
