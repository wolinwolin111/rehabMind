# 临床内容与资料库分工

`康复思路数据库与产品整改方案_v1.0.docx` 要求保留 v3.7 的核心关系，并补充临床解释层。当前以独立扩展工作簿承载新增字段，避免改动原始基线。编译后的 `build/knowledge/runtime.json` 同时包含核心表和扩展表。

康复思路页按 RegionClinicalMap 的维度、组别、顺序和展示方式组织项目。扩展内容通过 AssessmentFindingMap 的 `map_id` 关联到具体表现，再由 `Feature_ID` 关联处理目标和方法；页面只控制展开层级，不自行编写临床句子。未扩展项目沿用 v3.7 的检查、Finding 和 Intervention。安全线索出现时普通处理参考隐藏。

当前扩展工作簿覆盖膝部 RegionClinicalMap 关联的 35 个唯一项目：35 项都有“为什么看”和具体表现。伸膝、屈膝、髌股、胫骨旋转、近端胫腓关节分别关联活动表现与方向性处理；膝部不再使用“膝及相关关节活动改善”“局部症状管理”占位。另有 5 项踝足扩展记录。扩展表共 40 项目的、80 条具体表现、93 条处理参考，全部仍为“待临床审核”。仅定位或原因未明的发现可以没有处理关联，不能用覆盖率要求强行补齐方法。

来源链接支持相应主题，不等于每条编辑归纳都是已验证的诊断规则。[2019 年髌股痛指南](https://www.orthopt.org/content/s/patellofemoral-pain-2019) 的理疗建议限定于髌股疼痛，不能用于排除整个膝部局部组织的超声或电刺激。正式发布前仍需临床审核。

## 2026-09-29 局部组织处理参考整改

- 重新编写膝部6个局部组织项目、18条发现，关联19组具体方法。髌腱、脂肪垫、鹅足和髂胫束相关情境分别列出；仅浏览展开，不自动诊断或安排训练阶段。
- 本轮不列冷疗/冰敷，不声称贴扎、超声、加压等一律有更强证据。脂肪垫保留减压贴扎与伸膝控制；鹅足保留区域贴扎、超声、TENS及伴拉长受限时的腘绳肌拉伸；髌腱列等长、慢速抗阻和储能训练。
- 损伤后肿胀列抬高、弹性加压、踝泵，并限定为普通软组织损伤情境。膝后原因未明肿胀不关联按摩、加压或理疗。皮肤触碰敏感单独对应触觉脱敏。
- 6条尚不能确定具体处理情境的发现保留解释且无处理参考，页面可展开解释，不回退到基线通用治疗。包括胫骨结节反应、内侧关节线压痛、外侧关节线/腓骨头压痛、膝后深部压痛、膝后包块/肿胀、不适位置不清。
- `InterventionReference.Source_Note` 保存内部证据范围、局限，与 `Source_URL` 同行维护，API不向页面输出。研究样本量、失访、组合治疗不能分离单项效果等说明不混入公开方法名称。
- 取消“每条膝部发现必须有处理参考”和“膝部禁止超声/电刺激”的宽泛校验；保留来源、外键、非空方法校验，并校验局部组织方法不回退到已删除的泛化文案。
- 原始v3.7核心库未修改；编辑前副本保存在 `build/authoring/backups/`。其余模块与肌肉状态文案未在本轮全面审核。

资料库承担需细读的操作方法和背景资料，单独审核后上架。术后康复按术式与阶段另建入口，不混入普通症状定位链。髋部尚无现行 Region，不能用临时页面内容代替数据库与定位合同。
