## 重建

Node.js 22.12或更新版本，Python 3与 `scripts/requirements.txt` 中的依赖。

```sh
npm ci
python3 -m pip install -r scripts/requirements.txt
npm test
npm run build
```

`npm test` 从数据库生成运行快照，从原模型生成表面标注，重新生成内容审计，再运行测试。所有构建文件输出至 `build/`，不依赖先前本机留下的审计文件。

`scripts/authoring/` 保存原来位于构建目录中的29个维护脚本。普通构建只需要Node、Python与openpyxl；工作簿编写脚本另需表格工具和相应本地参考资料。`build/authoring/` 保存运行审计、日志、备份和预览等产物。

正式数据库和原始3D资源纳入Git。重复资产ZIP、旧v3.4资产、本地依赖、构建缓存、原始记录私有索引、环境配置和签名密钥由忽略规则隔离。
