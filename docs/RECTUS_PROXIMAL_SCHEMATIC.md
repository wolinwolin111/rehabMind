## 实现

- 原资源文件保持完整；关闭“显示股直肌近端修正”可查看原模型。
- 单独显示股直肌时，替换模型坐标 y=0.800 以上的近端显示面，截面以下的原三角面、远端保持原位置。肌腹渐细段上端为y=0.8815，其上还有双头贴合的共同下段；肌腹收窄起点显著提前，渐细长度从26.5 mm增加到81.5 mm。使用120个连续截面；两侧截面宽度相邻变化小于2.5%，避免临近分叉才突然收窄。这里的尺寸为本模型参数，不是参考图量得的真实肌肉尺寸。
- 连续截面及源边缘切线构造共同过渡，分叉位置在两处起点下方。共同截面分成两条闭合轮廓，沿内侧分界共享边缘，分别向两处骨面收窄。肌腹和两处分支共用顶点与法线，连接处不再是封口肌腹加两条重叠细管。
- 两支外形参考用户3DBody图的宽根与渐细双头及最新分界标注：从y=0.8815开始的下段贴合到y=0.8945，共用9个分界采样点，并移除两支内部重叠的分隔壁，形成同一张连续外表面。相对最初贴合版分界累计下移8 mm，右侧局部向当前核查视角的右方施加2.5 mm平滑位移，左侧镜像处理；位移在肌腹接口和骨面截面归零。中心线调整也会影响最终分界坐标，最终位移不等于单项参数。13 mm共同段和局部位移均为模型调整参数，不是二维参考图测量值。
- 上段分别向两处起点展开，交界保留尖角，不圆成U形开口。只固定交界外轮廓的两个端点，外围按焊接曲面局部平滑；固定整个分隔面或过度平滑会产生脊线、缩颈，已撤掉这些做法。骨面锚点及接触截面不移动。
- 半截面到圆截面的变化分布在较长路径中；生成后渐进恢复肌腱圆截面，并按截面半径的单调包络与平滑下限控制渐细，防止颈后再次鼓起或骨端前异常缩颈。反折头中段向直头收拢，两支下段没有裂缝。
- 拉长过渡时，原先逐点使用源三角边切线会产生交叉翻折与深色沟壑，已改成统一的中心线／径向收窄斜率；截面浅凹痕沿长过渡逐步圆顺成椭圆。保留源截面边界，并检查补面法线朝外，避免靠颜色遮盖错误面片。
- 根部中心贴合具体记录的源三角面，不从全局最近骨面推断解剖名称；源骨骼哈希变化时，生成器拒绝沿用锚点。
- 第一次前移时，将接触截面限制在单个三角形内导致右侧直头半径错误缩至约0.073 mm，形成尖针，已修正。先恢复此前接受的圆钝端头半径（右约1.25 mm、左约0.40 mm），随后按用户要求略加粗10%（右约1.38 mm、左约0.44 mm），连接中心保持不动。接触环投影到同一骨性区域的相邻骨面上，限定在中心半径1.35倍范围内；移动点位和端头粗细分别记录，避免前移时再次变尖。反折头仍使用原记录面的接触环；精细附着足印依旧未认证。
- 直头骨端微调时，肌腹分隔轮廓保留原参考方向，与骨端锚点分别记录；避免微移一个连接点就旋转分隔面、改变另一肌头及共同肌腹的整体外形。
- 两处分支统一米白肌腱颜色，向绿色肌腹渐变；核查页与应用单独显示共用相同的渐变数据。颜色表示教学组织形态，不表示组织经过精确分割。支持原图对比、近端放大、旋转、骨盆半透明。
- 分支从共同轮廓沿向上切线接出；反折头在较低处开始向外弯，沿连续三次曲线由下向上接入记录的骨面，不再先升到骨面以上再回折。两处分支骨面锚点未改变。下移量为本模型形态调整参数，不是从参考图量得的真实尺寸；路径为形态近似，不宣称精确腱束走向。
- 两头的初始向上控制段由12 mm延长到16 mm，降低分开初段的横向变化速度，缓和分岔走向；两个骨面起点、接触截面及肌腹裁切接口保持原位。
- 反折头靠骨端的控制点由起点旁18 mm、下2.5 mm改为旁10 mm、下6 mm，将较集中的折转改成长弧线。
- 截图左侧肩部的2 mm局部内收未充分消除轮廓台阶，已撤掉。肌腹第88层至共同下段第12层重新按同一轮廓对应构造约30 mm连续渐细曲面，匹配两端切线，并限制每条轮廓轨迹不超出两端坐标、不向外回鼓。肌腹／肌头的旧分界不再决定此处外形；两侧旧接口的切线跳变从约2.5–2.6度降至约0.93–0.98度，连接点和尖角分岔保留。
- 修正段点选仍返回同侧股直肌，既有区域定位、圈选和康复数据库不变。
- 直头前移、加粗后，原生成方式连带改变共同过渡段，肩部凸起复现。现单独保存肩部形态参考：肌腹、共同下段及直头前26层固定；骨端位移、朝向和10%加粗只从第27层逐渐作用到上段，末端重新贴合同侧骨面。上段消除鼓包时也限制修改范围，保留尖角交界。回归测试分别生成参考骨端与当前骨端，逐点比较固定段，防止再次连带变形。中心线控制点标记为上段调整前的参考坐标。

## 数据与边界

`scripts/authoring/rectus-landmarks.json`记录源骨骼ID、哈希、骨面编号、坐标和右侧用户截图依据、左侧对应依据。

`src/content/rectus-proximal-schematic.json`记录肌腹裁切与过渡、两处分支、骨面重心坐标、源几何哈希。

参考[Ryan等的近端附着研究](https://pubmed.ncbi.nlm.nih.gov/24793210/)、[Benes等的宏观及微观解剖研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC12178697/)，文献只提供解剖关系，不提供当前模型坐标。用户3DBody图用于参考双分支形态；用户本模型圈点图用于校正骨性位置。未复制3DBody网格或从二维截图推算真实三维坐标。

分支与过渡是教学形态修正，未认证完整附着足印，未重建关节囊或真实精细腱束。状态为 `anatomical_schematic_not_verified_tendon_or_footprint`。几何接触测试不等于解剖精度认证。
