## 内容与来源的处理方式

- 公开内容是一句目的、一句重点、具体表现和分类方法清单，保持思路助手的定位。
- 名称规范化属于编辑整理；“松解”整理为手法松解，“compex 激活”整理为 NMES 辅助募集，不增加手法步骤、剂量或治疗安排。
- 经验记录来源与指南来源分开保存；指南不被用来证明股外侧肌／腘肌松解或骰骨松动的具体经验对应。
- 同一病例的其他方法不自动归到当前问题。左右侧不一致、仅有评估没有处理、因果描述或结局不明确的内容不能作为明确对应的依据。
- 新具体发现之外，原库的发现及处理对应保留，避免只补充活动受限就丢失其他原有表现。
- 原记录中的患者姓名、个人情况和整篇病历不进入页面。内部来源采用内容哈希编号与行号，文件索引独立保存。
- 新增经验文案保留“待临床审核”。记录出现某方法不等同于验证该方法独立有效，方法之间没有优先顺序或自动适用结论。

## 已发现、尚未直接写入公开结论的内容

| 内容 | 后续处理 |
| --- | --- |
| 腓骨远端活动及松动 | 现有独立入口不足；单独补充远端关节项目及临床边界后再接入。不得用胫腓联合稳定性测试或近端胫腓关节替代 |
| 神经松动记录 | 记录中常与软组织松解共存；需核对神经线索、实际测试与对应神经，不普遍追加到肌肉紧张项目 |
| 超声及其他理疗 | 不根据同病例共现统一追加到所有局部痛、伸直受限或软组织紧张项目；原已专项审核的局部组织内容保留 |
| 骨盆卡旋、关节位置推断、由体征直接推病因 | 不转为自动判断规则；有明确可观察表现时单独整理 |
| 肩、颈、胸腰和髋部专项记录 | 可作为后续部位扩展的资料，尚未将这些新部位加入模型或产品模块 |
| 原库其余抽象文案与未覆盖项目 | 按具体条目继续核对，不能用本轮 13 条修改代表全库已完成审核 |
