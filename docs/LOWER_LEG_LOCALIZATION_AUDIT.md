# 小腿定位排查（2026-09-30）

实施更新（2026-10-01）：本排查是整改前的历史记录。统一表面定位已实施，保存落点回归及多视角射线检查通过，见 [统一定位实施记录](UNIFIED_SURFACE_LOCALIZATION.md)。下文保留原问题及旧实现说明。

## 范围与结论

依据用户的三类反馈排查：胫骨骨面进入前侧肌腹，小腿上段外侧进入髌下/髌腱，以及后侧进入后内侧。本轮检查当前实现与完整模型，没有修改正式定位规则、数据库或模型外观。

在同类空间落点复现了上段外侧进入膝前、后侧稍偏内进入后内侧。截图未记录完整相机、缩放和落点参数，不能声称逐像素还原。主要原因是标注范围、判定顺序和两套几何规则并存；不是已证实的射线加速索引错乱。

## 排除与尚未证明的因素

- 使用左右腿6个高度、10个水平方向、3个俯仰方向共360条实际网格射线。普通 Three.js 与当前间接 BVH 加速的首个命中面、命中点一致；加速过程保留原网格索引，未出现左右腿串选。
- 本次采样用于复现规则问题，不是临床准确率测试，不代表全部手机点击均正确。
- 当前下肢可见皮肤与命中皮肤在小腿没有被 `neutralizeSkin` 改形。模型主体截取/变形不是这几个小腿例子的已证实原因。
- 透明皮肤下可见的深层骨面不等于皮肤落点处必然是浅表骨面；后续不能简单地让所有骨骼射线命中都覆盖软组织选择。

## 修正顺序

1. **统一小腿定位规则。** 使用同一套左右腿、分高度的解剖参照，接通前、后、内、外侧；退出固定中心回退与局部补丁混用。保留现有区域ID与临床内容关联。
2. **修正膝与小腿交界。** 原标签作为候选，校验高度与方位。髌下/髌腱入口仅保留其真实前方范围；上段外侧关联腓骨头/近端胫腓与外侧肌群。膝后与小腿上段入口限定在后方，不能包住纯外侧。
3. **区分后侧与后内侧。** 结合实际皮肤落点的前后/内外方向及表面朝向，后方为主先归后侧，明确向内的后内侧表面再归后内侧。中下段跟腱与周围肌腹分别校验，避免用一条横向阈值把后侧切走。
4. **校准胫骨浅表骨面。** 读取现有左右胫骨网格，按高度定位前缘及内侧骨面，并与邻近皮肤和观察方向对应；区分 LL-R-002、内侧入口与 LL-R-001。不能仅依据深层骨骼是否被射线穿过来分类。
5. **验证用户指出的反例。** 覆盖正面、斜前、纯外侧、后面、斜后及俯仰视角；对比骨面与旁侧软组织、上段外侧与真正膝前、后侧与真正后内侧。入口应随实际身体表面位置保持一致，不随视角名称改变分类。

本批先修定位，临床内容仍由既有区域/位置ID读取；仅在真实交界需要同时显示相邻组织时调整位置指南。不另造一套页面区域选择或答案确认流程。
